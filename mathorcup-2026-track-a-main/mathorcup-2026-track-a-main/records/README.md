# 过程记录

每位成员在`ai/A/`、`ai/B/`、`ai/C/`按日期或任务分文件保存AI记录；总控自身研究可用`ai/control/`。重要核心决定在`decisions/`按编号分文件保存。模板位于根目录`templates/`。

工具任务记录可放`tools/A/`、`tools/B/`、`tools/C/`，或在现有manifest/证据表提供等价字段并链接，遵守docs/TOOL_WORKFLOW.md。

避免三人同时改一张共享大表。实验原始日志与大产物留在本地runs，轻量指标和验收证据放入reports并指明run_id、版本和复现方法。最终PDF说明由这些真实记录汇总。
