# 待澄清的数据口径

这是供队内和队长整理的清单，尚未向任何外部人员发送。可向组委会询问赛题数据/要求的歧义；不向队外人员求解建模方案。

1. **问题1评分尺度**：附件4与原研究标准化S4完全一致，原作者按品鉴者标准化并汇总。若要求输出原始0–6，是否提供原始逐品鉴者数据、完整转换流程，或赛事指定映射？能否提交标准化预测及明确假设的分级估计？
2. **目标范围**：附件4有50指标，A_/F_各15；评分卡另有两个无训练标签的Acetaldehyde项。题目“约40维”具体要求哪些字段？
3. **模板公式**：3.xlsx summary中barnyard指向Stale hops位置，是否有修正版或官方字段映射？
4. **化学尺度**：pH、ethanol等与校准表log10对应，部分其他列有不一致及零值替换。是否提供逐列预处理、检测限和单位说明？
5. **缺陷约束**：t2n缺阈值，Stale hops缺单一化学测量；阈值均值/中位版本不一致。赛事是否指定约束阈值和代理规则？

问询附件可用research/scoring-scale-investigation.md和target-unit-findings.md中的最小证据。收到正式答复后保存原文与日期，升级数据契约，重跑受影响实验。
